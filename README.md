# MesaCrítica

Aplicación Android de interfaz de reseñas de restaurantes para la Evaluación Sumativa 1 (Aplicaciones Móviles para IoT, INACAP).

Incluye seis pantallas: acceso, registro, lista de reseñas, agregar, detalle y asistente IA. Esta evaluación trabaja exclusivamente la interfaz; no conecta Firebase ni Gemini.

Abrir la carpeta del repositorio como proyecto en Android Studio, sincronizar Gradle y ejecutar en emulador. Comprobar los layouts en modo claro y oscuro.

**Pendiente de verificación:** compilación y vista en emulador; commits individuales de los dos integrantes.
